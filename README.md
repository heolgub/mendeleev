# Chemical Elements Explorer

Консольное приложение на Python для изучения таблицы Менделеева.

## Возможности

- Случайный элемент с фактом, свойствами и применением.
- Поиск элемента по названию или символу.
- Игра «Угадай элемент» с 3 попытками и подсказками.
- Сложный режим (угадывание по свойствам).
- Категории: щелочные металлы, галогены, благородные газы.
- Статистика правильных и неправильных ответов.
- Сохранение статистики в JSON.
